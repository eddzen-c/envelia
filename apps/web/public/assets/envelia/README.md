# Assets públicos de Envelia

Paquete web optimizado para el rediseño de Inicio, Plantillas, Cómo funciona, Precios, Inspiración, Ayuda y Contacto.

- Las imágenes visuales están en WebP.
- Los nombres y rutas son estables, cortos y sin espacios.
- Las tarjetas de precios, textos, botones e iconos funcionales deben construirse con HTML, CSS y SVG; no deben incrustarse como imágenes.
- `asset-manifest.json` documenta dimensiones, tamaño, SHA-256 y finalidad de cada archivo.
- Rutas de Next.js: usa valores como `/assets/envelia/home/hero.webp`.

Los originales y las capturas de referencia no se incluyen para evitar peso y duplicación en producción.
